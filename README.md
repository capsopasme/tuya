# 涂鸦蹦蹦

一路向上跳、躲开怪物、别掉下去的手绘风小游戏，纯 HTML5 Canvas 实现，玩法和操作参照经典的"向上跳"类游戏。主角"小海星"、怪物和全部美术都是原创的。

## 在手机上玩

**安卓 APK（推荐）**

1. 发版：在 GitHub 网页上新建一个 Release（tag 填 `v1.2.0` 这种格式），或者命令行 `git tag v1.2.0 && git push origin v1.2.0`，两种都行。
2. 等 Actions 里的 *Build Android APK* 跑完，APK 会自动挂到这个 Release 上，在 **Releases** 页下载 `tuya-1.2.0.apk` 安装。
   某个版本没挂上 APK 时，可以在 Actions 里手动运行 *Build Android APK*，填上那个 tag 补发。
3. 日常 push 到 main 也会构建，APK 在该次运行的 Artifacts 里。

APK 是个全屏 WebView 外壳，游戏离线运行，不需要任何权限；倾斜用的是原生加速度计，返回键会先暂停/返回菜单再退出。

签名：默认用 `android/fallback.keystore`（公开的非机密密钥，只是保证每次构建签名一致、能覆盖安装升级）。想用自己的密钥，在仓库 Secrets 里配 `KEYSTORE_BASE64`、`KEYSTORE_PASSWORD`、`KEY_ALIAS`、`KEY_PASSWORD` 即可，换密钥后需要先卸载旧版一次。

**网页版（可选）**

仓库 Settings → Pages → Source 选 "GitHub Actions"，然后手动运行 *Deploy web version*。手机浏览器打开后"添加到主屏幕"即可全屏游玩（倾斜依赖浏览器开放运动传感器）。

## 操作

| | 手机 | 键盘 |
|---|---|---|
| 左右移动 | 左右倾斜手机（只有倾斜这一种方式；设置里可调灵敏度，并有实时倾斜指示条） | ← → 或 A D |
| 射击 | 点击屏幕：自动瞄准屏幕里最近的怪物（带提前量），没有怪物时朝点击方向发射 | 空格 / ↑ |
| 暂停 | 右上角暂停键，或返回键 | P / Esc |

角色走出屏幕一侧会从另一侧出现。踩到怪物头上可以踩死它；碰到怪物、黑洞、UFO 光束或掉出屏幕底部则游戏结束。

道具：弹簧、蹦床、螺旋桨帽、喷气背包，以及终极道具**飞翼**（3500 分以后才会出现，比喷气背包还稀有）：一对大翅膀带着小海星以喷气背包 1.6 倍的速度连飞 5 秒多，一路撞飞怪物、撞散黑洞、无视 UFO 光束，收翅膀时再用力扇一下，并附带 1.6 秒金色护盾（期间撞到怪物是怪物被撞飞）。参数在 `DJ.C.WING_*`、`SHIELD_T`。

**紫黑飞翼**（5000 分以后才会出现，比白色飞翼还稀有）：黑紫色的翅膀上有流动的虹彩光泽，速度是白色飞翼的 1.4 倍（同样 5 秒能多飞三成多的高度），撞击范围也更大。拿到的一瞬间先把一圈紫色星屑“吸”进来，再炸开深紫色冲击波、霓虹细环、五臂漩涡和满天黑紫色羽毛，屏幕暗一下；飞行中小海星整个旋转起来（3D 模式下是真的在光照里转，高光和影子方向不变），身后拖着跟着一起转的紫色残影、螺旋甩出去的星屑，两圈反向转动的符文环和三颗绕身彗星。结束时旋转减速、带一点过冲回正，护盾是紫色的。参数在 `DJ.C.DARK_*`。

**慢落**：用完任何道具（弹簧、蹦床、螺旋桨、喷气背包、两种飞翼）之后，冲到顶开始往下掉的那段会慢慢飘下来——重力只有平时的四成、最大下落速度不到一半，两条手臂向上摊开、身体轻轻左右荡，身后飘着和道具同色的小光点；落到普通平台上立刻恢复正常。上升段完全不受影响，所以弹簧、蹦床不会因此弹得更高。参数在 `DJ.C.GLIDE_*`。

**身体倾斜和蓄力**：空中身体会朝移动方向歪一点；每次落到平台上腿被压扁的那一下是“蓄力”——身体朝你倾斜手机的方向狠狠压下去（以前脚为支点，后脚抬起来），倾斜得越狠身体压得越扁，起跳时被甩回来还带一点过冲，像侧身发力蹬出去。纯视觉，不影响碰撞和手感。参数在 `DJ.C.LEAN`、`LEAN_CHARGE`。

**畅快模式**：设置里的开关（默认关，下一局开始生效）。开启后道具爆率大幅提高、出现得更早（弹簧、蹦床开局就有，螺旋桨 250 分、喷气背包 600 分、飞翼 1500 分、紫黑飞翼 2500 分起），怪物和黑洞更晚出现、间隔更远、数量大约少一半多；游戏中分数栏右侧会显示「畅快」标签。参数在 `js/config.js` 的 `DJ.CHILL`。排行榜和最高分与普通模式共用。

主角：设置里可以切换 **2D / 3D**（默认 3D）。3D 模式下小海星是用 WebGL 实时光线步进渲染的软糖立体公仔——有光照、高光、阴影和投在纸面上的影子，大肚子真的往外鼓、落地时 duang duang 地晃，左右移动时身体会转过去露出肚子的侧面轮廓，和手绘 2D 的笔记本世界形成对比。设备不支持 WebGL 时自动退回 2D。主角整体大小由 `DJ.C.HERO` 控制（画面和碰撞框一起缩放）。弹簧和蹦床只要身体中心落在它所在的那块平台范围内就会触发，不必精确踩在道具上（`DJ.C.ITEM_REACH` 可调）。小海星的肚子是两层阻尼弹簧，每次起跳都会 duang duang 狠狠晃几下（`BELLY_*` 可调）。平台：绿色（普通）、蓝色（会移动）、白色（踩一次消失）、棕色（一踩就碎）。

## 动画为什么顺

- 物理固定按 1/120 秒一步走，画面在两步之间插值，60/90/120Hz 的屏幕都匀速平滑，掉帧也不会一顿一顿。
- 镜头是缓动跟随（不是硬贴着角色）；角色的肚子、肚皮、手臂、脸朝向、空中拉伸都是弹簧或指数平滑，没有任何姿态是瞬间切换的。
- 落地有尘土、平台会被踩得下沉再弹回，弹簧/蹦床有冲击环，高速时有速度线；界面切换有淡入弹出，按钮依次出现、按下有弹簧回弹，分数数字滚动追上。
- 安卓外壳向系统申请 120Hz 刷新率（设置里可切到 60，见下）。

## 省电

- **帧率**（设置里，默认 120）：切到 60 时安卓壳会让屏幕本身也切到 60Hz（选同分辨率下最接近的显示模式），浏览器里则每隔一帧才画一次。物理永远按 1/120 秒一步走、画面插值，所以手感完全一样，只是没那么丝滑。手机发热时这是最有效的一档。
- **为什么要专门“投票”120Hz**：Android 15 起系统按 View 的投票动态选刷新率，普通 View 默认只投 60Hz，只有手指在屏幕上时才临时提到高刷。这个游戏全程靠倾斜、几乎不碰屏幕，不额外声明就会一直被压在 60Hz。所以安卓壳在 120 档时会让 WebView 明确投 120Hz（`setRequestedFrameRate`），并关掉窗口的省电降帧（`setFrameRatePowerSavingsBalanced(false)`）；这两个是新系统才有的方法，老系统上自动跳过。
- **性能信息**（设置里，默认关）：游戏中分数栏下面显示 `屏幕 120Hz · rAF 120 · 画 120 帧 · 卡顿 0 · JS 1.2ms`。屏幕 = 系统报告的当前刷新率；rAF = WebView 每秒实际跟屏幕刷新了几次；画 = 每秒真正画了几帧；卡顿 = 最近 2 秒里帧间隔超过正常 1.5 倍的次数；JS = 每帧脚本耗时（不含 GPU）。觉得卡的时候打开看一眼，就知道是屏幕被降频了、还是渲染跟不上。
- 3D 主角：着色器先用一次乘加判掉离身体很远的像素（整块渲染区域大部分是空的），光线从更近的地方出发、命中阈值按像素大小放宽，环境光遮蔽少采样一次；渲染分辨率最高 2.2 倍。每一帧都按最新姿态重新渲染（曾经试过隔帧渲染省电，但肚子和手臂是眼睛一直盯着的东西，隔帧在 120Hz 下看起来就像 60 帧）。
- 背景方格做成一个整数像素的小贴图平铺（一次填充，不再每帧描一百多条整屏长线）；平台渐变缓存复用。
- 暂停、排行榜、结算界面进场动画放完、也没人碰屏幕时完全不重画。
- 不在游戏中且 3 秒没出声时挂起音频设备。
- `node tools/bench.js` 在无头浏览器里比较每帧渲染耗时（软件渲染，只看相对变化）。

## 开发

不需要构建，直接用任意静态服务器打开：

```sh
npm start            # http://localhost:8080
npm test             # 关卡可达性模拟 + 手机浏览器冒烟测试（需要 Playwright）
npm run snap         # 把各种状态截图到 tools/out/，肉眼检查画面
```

```
index.html, css/, js/     游戏本体
  config.js               常量、物理参数、随机数
  world.js                游戏逻辑（不依赖 DOM，可在 Node 里直接跑）
  render.js               画面：背景、平台、道具、主角（2D）、怪物
  hero3d.js               3D 主角（WebGL SDF 光线步进，贴回 2D 画布）
  ui.js                   菜单、设置、排行榜、结算
  input.js, main.js       输入（倾斜/触屏/键盘）与主循环
  audio.js                WebAudio 现场合成音效，没有音频文件
tools/                    sim.js 模拟、smoke.js 冒烟、snap.js 截图、bench.js 渲染耗时
android/                  安卓外壳（构建时把上面的游戏文件复制进 assets）
.github/workflows/        android.yml 构建 APK，pages.yml 部署网页版
```

想调手感，改 `js/config.js` 里的 `DJ.C`（重力、起跳速度、水平加速度等）；改名字需要同时改 `js/ui.js` 的标题、`index.html`、`manifest.webmanifest` 和 `android/app/src/main/res/values/strings.xml`。
